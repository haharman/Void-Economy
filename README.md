# Void Economy

> 宇宙と神社をテーマにした、2Dピクセルアートの探索アドベンチャー（プロトタイプ）

**Void Economy** は、インタラクティブアート系企業のインターンシップ用に制作している、ナラティブ主導の2Dゲームです。
惑星間を飛び回り行商を行う本編構想のうち、本リポジトリでは **その惑星のひとつ「神社（Surface）」を歩き、参拝する体験** をプロトタイプとして実装しています。

Unity / C# で開発し、リアクティブプログラミング（R3）とMVPライクなレイヤードアーキテクチャを採用しています。

## 実装済みの機能

本プロトタイプで体験できるのは、神社（Surface）シーンの **「歩いて、見て、話しかける」** 一連の流れです。

- **多層パララックススクロール背景**
  カメラ移動量に応じて複数の背景レイヤーを動的に生成・配置。奥行き（`depthFromPlayer`）やループ／繰り返し描画に対応した自作パララックスシステム。

- **プレイヤーの横移動と歩行表現**
  入力に応じた移動・スプライト反転・歩行アニメーション、足音（フットステップ）の再生。

- **エンティティとの会話（参拝体験）**
  地蔵や案内役などのエンティティに近づくと頭上にインタラクションガイドを表示。`E` キーで [Yarn Spinner](https://yarnspinner.dev/) による分岐付きダイアログを開始。

- **インタラクションガイド表示**
  会話可能な対象を検出すると「`E`: 話しかける」相当のプロンプトを動的に表示／非表示。

- **BGM 再生システム**
  トラックリストに基づく BGM のフェード再生・切り替え、足音・ワンショット音の管理を行うオーディオシステム（DOTween 使用）。

- **シーン管理基盤**
  Title → Surface のシーン遷移と、シーンをまたいで永続する `GlobalRoot` による初期化。

> 行商（Economy）・宇宙航行（Space / 物理エンジン）・セーブ&ロードは設計・足場の実装段階であり、本プロトタイプのプレイ範囲には含まれません。

## アーキテクチャ

MVP ライクなレイヤードアーキテクチャを採用し、Assembly Definition（`.asmdef`）でレイヤー間を疎結合に保っています。

```
View ◄──────── Presenter ────────► Model
                                      │
                        ┌─────────────┴─────────────┐
                        │                           │
                     Core (共有ユーティリティ)     Root (エントリポイント)
```

**依存方向のルール:** View → Presenter → Model → Core（上方向への依存は禁止）

| レイヤー | 役割 |
| --- | --- |
| **Core** | 座標系（`SurfacePosition` / `SpacePosition`）、列挙型、汎用ユーティリティ |
| **Model** | 業務ロジックとデータ（`PlayerModel` / `EntityModel` / `YarnModel` / `GlobalStateModel` など）。UIを知らない |
| **Presenter** | 入力→Model、Model→View のルーティング |
| **View** | 描画・UI。R3 の購読で Model を監視（直接変更はしない） |
| **Root** | シーンのブートストラップ（`GlobalRoot` / `SurfaceRoot` / `TitleRoot`） |

### データフロー例

```
入力（キー）
  → View が入力イベントを発火
  → Presenter が受け取り Model を呼ぶ
  → PlayerModel が状態を更新（リアクティブ）
  → View が Observable を購読して描画を更新
```

## 使用技術

- **Unity** — Universal Render Pipeline (URP)、2D / Input System / Cinemachine
- **C#**
- **[R3](https://github.com/Cysharp/R3)** — リアクティブプログラミング（Model の状態を `Observable<T>` で公開し、View/Presenter が購読）
- **[Yarn Spinner](https://yarnspinner.dev/)** — 分岐対応のダイアログスクリプティング
- **DOTween** — オーディオのフェードなどのトゥイーン
- **Aseprite** — ピクセルアートのインポート

## ディレクトリ構成（抜粋）

```
Void Economy/                       ← Unity プロジェクトフォルダ
├── Assets/
│   ├── Scripts/
│   │   ├── Core/                    ← 座標系・列挙型・ユーティリティ
│   │   ├── Model/                   ← PlayerModel, EntityModel, YarnModel ほか
│   │   ├── Presenter/               ← 入力-Model-View のルーティング
│   │   ├── View/                    ← パララックス・プレイヤー描画・オーディオ・UI
│   │   └── Root/                    ← シーンのブートストラップ
│   ├── Scenes/                      ← Title / Surface ほか
│   └── Yarn/                        ← ダイアログスクリプト
└── Packages/manifest.json          ← UPM パッケージ（R3, Yarn, Cinemachine など）
```
